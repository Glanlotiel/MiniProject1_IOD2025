# The Oxwaethan Dice Roller

## TTRPG Dice Roller and Simple 4d6 Drop Lowest Character Creator.

- This project is a starter website designed to be a dice roller for all tabletops, but focused more on Dungeons and Dragons.
- Currently the scope is a d4-d20 dice roller with any number of dice alongside an automatic character creator.
- Made for IOD 2025 Software Engineering Course to test early knowledge.
